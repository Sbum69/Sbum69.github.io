03How I work

Fast with AI.
Careful with what matters.

  1. 01

    Audit

    Read the code and the data first. Write down what exists, what's risky and what's missing before touching anything.

  2. 02

    Build

    Ship in small blocks with a range of tools and different AI agents to move faster, while I own the architecture and the security decisions.

  3. 03

    Test

    Every block is checked: unit tests, policy checks, manual QA. Each result is marked PASS, FAIL, BLOCKED or NOT RUN, with no grey areas.

  4. 04

    Report

    A written report closes every block, so the next person (or the next me) knows exactly where things stand. Built for async, remote teams.
